# AirWise 🌍

### Air Pollution Monitoring Using Digital Technology

AirWise is an academic project developed to explore how digital technology can be used to present air pollution-related information.

### Technologies Used
- HTML
- CSS
- JavaScript

### Project Overview
The project focuses on presenting air pollution-related information through a simple and accessible web interface.
